# 🛍️ Nostra — E-Commerce Website

A modern and responsive **e-commerce website** built using **HTML, CSS, and JavaScript**. Nostra provides a clean shopping interface with product collections, promotional sections, responsive navigation, and an interactive user experience.

## 🌐 Live Demo

🚀 **[View Nostra Live](https://aswindevakumar98-dsan.github.io/Nostra/)**

---

## 📌 About The Project

**Nostra** is a responsive e-commerce website created to practice and demonstrate front-end web development skills.

The project focuses on:

* Responsive web design
* Clean and modern UI
* Interactive JavaScript functionality
* Product collection presentation
* Mobile-friendly navigation
* Reusable HTML/CSS components
* Real-world e-commerce website structure

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/aswindevakumar98-dsan/Nostra.git
```

### 2. Navigate to the Project

```bash
cd Nostra
```

### 3. Run the Project

Since Nostra is a front-end project, you can simply open:

```text
index.html
```

in your browser.

For development, you can also use **VS Code Live Server**.
